Bash Scripting – Practical Tutorial

Learn Bash scripting through practical examples, commands, and exercises.

1. Variables in Bash

Variables are used to store information that can be reused throughout a Bash script. You can store values such as usernames, directory paths, IP addresses, service names, file names, and configuration values.

Declaring a variable

#!/bin/bash

name="Manohar"
environment="production"
server_ip="192.168.1.10"

echo "Name: $name"
echo "Environment: $environment"
echo "Server IP: $server_ip"

Important variable rules

  • Do not use spaces around the assignment operator.
  • Variable names are case-sensitive.
  • Use name="value", not name = "value".
  • Use $variable to access a variable's value.
  • Use curly braces when needed: ${name}.

Using variables inside strings

#!/bin/bash

service="nginx"

echo "Checking $service service"
echo "Service name: ${service}"

Command substitution

Command substitution stores the output of a command in a variable. Use $(command) syntax. 

#!/bin/bash

current_date=$(date)
hostname=$(hostname)
current_user=$(whoami)

echo "Date: $current_date"
echo "Hostname: $hostname"
echo "User: $current_user"

Environment variables

Environment variables are available to processes started by the shell. Use export to make a variable available to child processes. 

#!/bin/bash

export APP_ENV="production"
export APP_PORT=8080

echo "$APP_ENV"
echo "$APP_PORT"
Important: Bash variables are not declared with fixed data types. Bash primarily treats variable values as strings, although arithmetic operations can interpret numeric values.

2. User Input in Bash

The read command accepts input from the keyboard and stores it in a variable. It is useful for interactive scripts that require a username, directory, or other input.

Basic read command

#!/bin/bash

echo "Enter your name:"
read name

echo "Welcome, $name"

Using read with a prompt

#!/bin/bash

read -p "Enter server name: " server

echo "Selected server: $server"

Reading sensitive input

Use -s to prevent typed input from being displayed. This is useful for password prompts. 

#!/bin/bash

read -s -p "Enter password: " password
echo
echo "Password received."

Reading multiple values

#!/bin/bash

read -p "Enter first and last name: " first last

echo "First name: $first"
echo "Last name: $last"

3. Quoting and Special Characters

Quoting controls how Bash interprets spaces, variable expansion, and special characters. Incorrect quoting can cause scripts to behave unexpectedly, especially when file paths contain spaces.

Double quotes

Double quotes preserve spaces while allowing variable and command substitution. 

#!/bin/bash

name="Manohar"
echo "Welcome $name"
echo "Today is $(date)"

Single quotes

Single quotes preserve the literal text. Variables inside single quotes are not expanded. 

#!/bin/bash

name="Manohar"

echo 'Welcome $name'
echo "Welcome $name"

Unquoted variables

Unquoted variables can undergo word splitting and pathname expansion. This can cause problems when values contain spaces or wildcard characters. 

#!/bin/bash

directory="/var/log/my application"

# Safer
ls "$directory"
Best practice: Quote variable expansions by default, for example "$variable", unless you specifically need word splitting or glob expansion.

4. Arithmetic Operations and Operators

Bash supports arithmetic operations for calculations involving integers. The $(( )) syntax is commonly used for arithmetic expansion.

Arithmetic operations

#!/bin/bash

a=20
b=5

echo "Addition: $((a + b))"
echo "Subtraction: $((a - b))"
echo "Multiplication: $((a * b))"
echo "Division: $((a / b))"
echo "Remainder: $((a % b))"

Increment and decrement

#!/bin/bash

count=10

((count++))
echo "After increment: $count"

((count--))
echo "After decrement: $count"

Comparison operators

OperatorMeaning
-eqEqual to
-neNot equal to
-gtGreater than
-ltLess than
-geGreater than or equal to
-leLess than or equal to

Example using comparison operators

#!/bin/bash

cpu_usage=85

if [ "$cpu_usage" -gt 80 ]; then
    echo "High CPU usage detected"
else
    echo "CPU usage is normal"
fi

String comparison

#!/bin/bash

environment="production"

if [ "$environment" = "production" ]; then
    echo "Production environment"
fi

5. Conditional Statements

Conditional statements allow a script to make decisions based on conditions. They are commonly used in automation to check services, files, directories, and system resources.

if statement

#!/bin/bash

status="running"

if [ "$status" = "running" ]; then
    echo "Application is running"
fi

if-else statement

#!/bin/bash

service="nginx"

if systemctl is-active --quiet "$service"; then
    echo "$service is running"
else
    echo "$service is not running"
fi

if-elif-else statement

#!/bin/bash

disk_usage=92

if [ "$disk_usage" -ge 90 ]; then
    echo "Critical: Disk usage is above 90%"
elif [ "$disk_usage" -ge 75 ]; then
    echo "Warning: Disk usage is high"
else
    echo "Disk usage is normal"
fi

File and directory conditions

ConditionPurpose
-fChecks whether a regular file exists
-dChecks whether a directory exists
-eChecks whether a path exists
-rChecks whether a file is readable
-wChecks whether a file is writable
-xChecks whether a file is executable

Checking a directory

#!/bin/bash

directory="/var/log"

if [ -d "$directory" ]; then
    echo "Directory exists"
else
    echo "Directory does not exist"
fi

6. Loops in Bash

Loops execute a block of commands repeatedly. They are useful for processing multiple files, checking several servers, monitoring services, and performing repetitive administrative tasks.

for loop

#!/bin/bash

for server in web01 web02 db01
do
    echo "Checking server: $server"
done

for loop with a range

#!/bin/bash

for number in {1..5}
do
    echo "Number: $number"
done

while loop

#!/bin/bash

count=1

while [ "$count" -le 5 ]
do
    echo "Count: $count"
    ((count++))
done

until loop

An until loop continues executing until its condition becomes true. 

#!/bin/bash

count=1

until [ "$count" -gt 5 ]
do
    echo "Count: $count"
    ((count++))
done

break and continue

#!/bin/bash

for number in {1..10}
do
    if [ "$number" -eq 5 ]; then
        continue
    fi

    if [ "$number" -eq 8 ]; then
        break
    fi

    echo "$number"
done

continue skips the current iteration, while break terminates the loop.

7. Functions in Bash

Functions are reusable blocks of code. They help organize scripts into smaller sections and avoid repeating the same commands.

Creating a function

#!/bin/bash

greet() {
    echo "Welcome to Bash scripting"
}

greet

Functions with arguments

Arguments passed to a function can be accessed using positional parameters. $1 represents the first argument, $2 the second, and $# the number of arguments. 

#!/bin/bash

create_user() {
    username="$1"
    echo "Creating user: $username"
}

create_user "developer"

Returning values

Bash function return codes indicate success or failure. Use echo or another output mechanism when you need to return a calculated value. 

#!/bin/bash

add_numbers() {
    result=$(($1 + $2))
    echo "$result"
}

sum=$(add_numbers 10 20)

echo "Sum: $sum"

Checking function return status

#!/bin/bash

check_service() {
    systemctl is-active --quiet nginx
}

if check_service; then
    echo "Nginx is active"
else
    echo "Nginx is inactive"
fi

8. Arrays in Bash

Arrays allow you to store multiple values under a single variable name. They are useful when working with lists of servers, users, packages, or files.

Creating an indexed array

#!/bin/bash

servers=("web01" "web02" "db01")

echo "${servers[0]}"
echo "${servers[1]}"
echo "${servers[2]}"

Accessing all array elements

#!/bin/bash

servers=("web01" "web02" "db01")

echo "All servers: ${servers[@]}"
echo "Number of servers: ${#servers[@]}"

Iterating through an array

#!/bin/bash

services=("nginx" "ssh" "cron")

for service in "${services[@]}"
do
    echo "Checking $service"
done

Adding and removing elements

#!/bin/bash

servers=("web01" "web02")

# Add an element
servers+=("db01")

# Remove the element at index 1
unset 'servers[1]'

echo "${servers[@]}"

Associative arrays

Associative arrays store values using named keys rather than numeric indexes. They require Bash 4 or newer. 

#!/bin/bash

declare -A server

server[name]="web01"
server[ip]="192.168.1.10"
server[environment]="production"

echo "Name: ${server[name]}"
echo "IP: ${server[ip]}"
echo "Environment: ${server[environment]}"

9. File Handling and Redirection

Bash scripts frequently create, read, append, and process files. Redirection allows you to control where command output and errors are sent.

Writing to a file

#!/bin/bash

echo "Application started" > application.log

The > operator creates a file or overwrites its existing contents.

Appending to a file

#!/bin/bash

echo "Application running" >> application.log

The >> operator appends output without deleting existing contents.

Reading a file

#!/bin/bash

while IFS= read -r line
do
    echo "Line: $line"
done < servers.txt

Checking whether a file exists

#!/bin/bash

file="/etc/hosts"

if [ -f "$file" ]; then
    echo "File exists"
    cat "$file"
else
    echo "File not found"
fi

Output and error redirection

#!/bin/bash

# Redirect standard output
ls /var/log > output.log

# Redirect standard error
ls /invalid-path 2> error.log

# Redirect both output and errors
ls /var/log /invalid-path > result.log 2>&1

Pipes

The pipe operator | sends the output of one command as input to another command. 

#!/bin/bash

ps aux | grep nginx
df -h | grep -v tmpfs
cat /etc/passwd | wc -l

10. Exit Status, Arguments and Debugging

Exit statuses indicate whether a command or script completed successfully. They are important in automation pipelines because other tools can use the exit status to determine whether a task succeeded or failed.

Understanding exit status

The special variable $? contains the exit status of the most recently executed command. Conventionally, zero indicates success and a non-zero value indicates failure. 

#!/bin/bash

mkdir /tmp/bash-demo

if [ "$?" -eq 0 ]; then
    echo "Directory created successfully"
else
    echo "Directory creation failed"
fi

Using exit

#!/bin/bash

if [ ! -d "/var/log" ]; then
    echo "Required directory is missing"
    exit 1
fi

echo "Validation successful"
exit 0

Command-line arguments

Arguments can be passed to a script when executing it.

VariableMeaning
$0Script name
$1First argument
$2Second argument
$#Number of arguments
$@All arguments as separate words when quoted
$?Previous command's exit status
$$Current shell process ID

Example script using arguments

#!/bin/bash

if [ "$#" -lt 2 ]; then
    echo "Usage: $0 <username> <environment>"
    exit 1
fi

username="$1"
environment="$2"

echo "Username: $username"
echo "Environment: $environment"

Run the script:

chmod +x deploy.sh
./deploy.sh developer production

Debugging Bash scripts

Bash provides options to help identify errors during script execution. 

# Display commands as they execute
bash -x script.sh

# Check syntax without executing the script
bash -n script.sh

# Enable debugging inside a script
set -x

# Disable debugging
set +x

Using strict mode

#!/bin/bash

set -euo pipefail

echo "Starting script"

name="Manohar"
echo "Hello $name"

What these options do:

  • -e: Exit when an unhandled command fails, subject to Bash's conditional and compound-command rules.
  • -u: Treat unset variables as errors in most expansions.
  • -o pipefail: Make a pipeline fail if a command in it fails, rather than only using the last command's status.
Important: Strict mode does not replace proper error handling. Test scripts carefully, especially when they modify files, users, services, or production infrastructure.

Final Practice: Server Health Check Script

Combine variables, conditions, command substitution, and exit statuses to create a simple server health check script. 

#!/bin/bash

set -u

SERVER=$(hostname)
DATE=$(date)
DISK_USAGE=$(df / | awk 'NR==2 {gsub("%","",$5); print $5}')

echo "Server Health Report"
echo "-------------------"
echo "Hostname: $SERVER"
echo "Date: $DATE"
echo "Root Disk Usage: ${DISK_USAGE}%"

if [ "$DISK_USAGE" -ge 80 ]; then
    echo "WARNING: Disk usage is high"
    exit 1
else
    echo "STATUS: Server disk usage is normal"
    exit 0
fi

How to Execute a Bash Script

# Create a script
nano script.sh

# Add the Bash shebang
#!/bin/bash

# Make it executable
chmod +x script.sh

# Execute the script
./script.sh

# Alternatively, execute through Bash
bash script.sh
